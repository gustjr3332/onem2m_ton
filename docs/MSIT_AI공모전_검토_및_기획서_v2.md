## 1. 적합성 검토

공고문이 요구하는 것: ① 일상의 불편 해소·삶의 질 향상 ② **신규** AI 서비스·기능 ③ 가사·육아·안전·복지·여가 등 **생활 밀착** ④ 미구현 기획 가능 ⑤ 3쪽 이내.

| 기준 | EdgePdM (A안) | PolaGrid (B안) |
|---|---|---|
| 생활 밀착도 | ✗ 공장·물류 설비. 국민 일상과 거리 멂 | △ 건물 채광이지만 집·교실·사무실 창가로 옮기면 일상 문제 |
| 대상 사용자 | 산업 정비사 | 일반 시민 (집, 학교, 사무실) |
| AI 필요성 | ○ 진동 기반 고장 분류 | ○ 카메라 눈부심 판별 (v2에서 규칙 기반 → AI로 이동 필요) |
| 공고 문구와의 결합 | ✗ oneM2M/MEC 중심 서술이 공모 취지와 무관 | △ 안전(눈 피로)·복지(고령자, 학생)·에너지로 연결 가능 |
| 실현 근거 | 없음 (부품 주문 전) | ○ 2025-1 서보+편광필름 동작 검증 프로토타입 |
| 걸림돌 | 주제 자체가 안 맞음 | 카메라 사생활 문제, 편광 하드웨어를 일반 가정에 설치하는 현실성 |

**판정**
- **EdgePdM 그대로 제출: 부적합.** 산업용이고 생활속 AI 주제와 어긋남. 다만 "설비 이상을 소리·진동으로 미리 감지"라는 핵심 기술은 **가전 버전으로 변환**하면 살릴 수 있음 (아래 v2-B).
- **PolaGrid: 방향은 맞음, 서술을 뜯어고쳐야 함.** oneM2M/MEC/Mp1 같은 대회 전용 용어를 빼고 "누가, 어떤 불편을, 어떻게 AI로 풀고, 어떻게 좋아지나"로 재구성.
- 공고는 "중복지원 불가"라 **한 편만 제출**하는 것을 전제로 하고, 확인 필요 (같은 분야에 두 편 가능한지 양식 문구 확인).

**추천: v2-A (PolaGrid 생활형)를 메인으로, 시간이 남으면 v2-B는 후속용 보관.** 이유: 직접 만든 동작 프로토타입이 있어 "실현 가능성" 설득력이 가장 강함.

## 2. v2-A — 창가 눈부심 AI (PolaGrid 생활형) 기획서 초안

### 제목(안)
**"블라인드 대신 AI가 빛을 고른다" — 우리집·교실 창가 눈부심 자동 조절 서비스, PolaGrid**

### 1) 일상의 불편 (문제)
- 낮에 창가에서 공부·재택근무·TV 시청을 하면 **눈부심** 때문에 블라인드를 내렸다 올렸다 반복하게 됨.
- 블라인드를 내리면 **낮인데도 조명을 켜야** 하고, 올리면 눈이 피로하고 화면이 안 보임. 여름엔 냉방 부담도 커짐.
- 수동 조작은 학생, 고령자, 몸이 불편한 사람에게 특히 번거로움. (복지 관점)

### 2) 아이디어 (무엇을)
- 창가에 **편광 필름 + 소형 모터**를 달고, 작은 카메라·조도센서가 실내 눈부심을 보고 **필름 각도를 자동 조절**. 시야는 유지하면서 눈부심만 줄임.
- 사용자는 앱에서 "책상 위 눈부심 줄이기 / 화면 반사 줄이기 / 밝게 유지" 모드만 선택.
- 블라인드처럼 빛을 **차단**하지 않고 편광으로 **선택적 감쇠**하는 점이 핵심 차별점.

### 3) AI 활용 방식
| 단계 | 내용 |
|---|---|
| 입력 | 저해상도 실내 영상(또는 밝기 분포) + 조도센서 값 + 시간대 |
| 판별 | 눈부심 유무·강도 분류 (경량 모델: scikit-learn 특징 기반 vs MobileNetV2 전이학습 → 비교해 선택) |
| 제어 | 판별 결과로 편광 각도 결정, 사용자가 수동 보정하면 선호도로 학습 (개인화) |
| 사생활 | **기기 안에서만 처리**, 영상 저장·전송 없음, 얼굴 정보 미사용. 원한다면 카메라 대신 밝기 격자 센서만으로도 동작하는 모드 제공 |

> 규칙 기반(임계값)만으로는 "AI 서비스"로 보기 어려우므로, 눈부심 판별과 개인 선호 학습을 AI 역할로 명시함.

### 4) 사용 장면 (시나리오)
1. 오후 3시, 학생이 창가 책상에서 공부. 서쪽 햇빛이 노트에 반사됨.
2. 카메라가 눈부심을 감지 → 필름이 회전해 반사광 감소. 조명은 켜지 않아도 됨.
3. 구름이 지나가면 다시 자동으로 밝게. 학생이 "조금 더 어둡게"를 누르면 그 선택이 다음번 판단에 반영.

### 5) 적용 확장 (가사·복지·여가·정책)
- **가정**: 재택근무, 아이 공부방, 거실 TV 반사.
- **학교·도서관**: 자리마다 다른 눈부심 문제를 자동으로 해결.
- **복지시설·경로당**: 고령자가 블라인드를 직접 만지지 않아도 됨.
- **정책 제안**: 공공건물·학교 리모델링 시 에너지 절감형 창 자동제어 보조 적용 검토.

### 6) 실현 가능성
- 2025-1 SW창의기초설계에서 **조도센서 + 서보모터 + 편광필름** 구조를 만들어 동작 검증 완료 (사진·영상을 부속자료로 첨부 가능).
- 신규 개발분은 눈부심 판별 모델과 앱 화면. 시연 영상 3분 이내로 제출 가능.

### 7) 기대 효과
- 눈 피로 감소, 낮 조명 사용 감소로 **에너지 절감 기대** (수치는 시연에서 조도·전력 비교로 직접 측정한 값만 기재. 근거 없는 절감률은 쓰지 말 것).
- 수동 조작 부담 제거로 고령자·학생의 이용 편의 향상.

### 제출 전 체크
- [ ] 편광이 눈부심(반사광)에 효과적이라는 물리 근거를 한 문장으로 정리 (편광 필터는 수평면 반사광 감쇠에 유효, 직사광에는 한계가 있음을 스스로 밝히면 신뢰도 상승)
- [ ] "블라인드/스마트 블라인드/전동 커튼 대비 무엇이 다른가" 비교 문단 1개
- [ ] 시연 영상 3분: 기존 프로토타입 + 판별 화면 목업
- [ ] 이 문서에서는 oneM2M/MEC 용어를 전부 제거함 (이 공모전에서는 불필요)

## 3. v2-B — 우리집 가전 소리 주치의 (EdgePdM 생활형, 후속용)

### 제목(안)
**"고장 나기 전에 먼저 말해주는 우리집 가전" — 소리·진동 기반 가전 이상 조기 알림**

- **불편**: 세탁기 진동 증가, 에어컨 팬 소음, 냉장고 컴프레서 소리 변화는 알아채기 어렵고, 완전히 고장 난 뒤에야 수리를 알아봄. 여름 에어컨·겨울 보일러처럼 필수 시기에 고장 나면 피해가 큼.
- **아이디어**: 스마트폰 마이크·가속도 센서(또는 저가 센서)로 가전 작동음을 짧게 수집, AI가 **평소 소리와 달라졌는지**를 판단해 "이번 주 안에 점검 권장"처럼 알림. 제조사 수리 접수 링크 연결.
- **AI 활용**: 우리집 가전의 "정상 소리"를 사용자별로 학습한 이상 탐지(정상만 학습). 진동·소리 스펙트럼 특징 + 경량 분류.
- **EdgePdM과의 연결**: 진동으로 고장 징후 분류하는 핵심 기술을 그대로 사용, 대상만 공장 모터에서 가전으로 변경.
- **약점**: 소리 데이터 수집 난이도, 기기별 편차, 생활 소음 분리. 소리 저장 없이 특징값만 기기 내 처리한다는 사생활 설계 필요.
- **판정**: 아이디어는 공고 취지에 잘 맞으나, **시연 근거(프로토타입)가 약함.** 제출한다면 세탁기 한 대 진동 데이터를 직접 녹음해 정상/이상 비교 그래프를 스크린샷으로 첨부해야 설득력이 생김.
